### How the profile is built

- **Animated SVG panels:** self-contained SVG + CSS/SMIL; no JavaScript is required in the README.
- **Tech orbit:** Node.js at the center, with Express.js and MongoDB as orbiting companions.
- **3D contribution city:** generated by `.github/workflows/profile-3d.yml`.
- **Contribution snake:** generated by `.github/workflows/github-snake.yml` and published to the `output` branch.

### Enable the animations

1. Open the repository's **Actions** tab and enable workflows if GitHub prompts you.
2. Run **3D contribution city** and **Generate contribution snake** manually once.
3. The workflows are also scheduled to refresh daily. The contribution city may take a few minutes to appear on the first run.
4. If GitHub shows a cached version of an SVG, increment its query string in this README (for example, `hero.svg?v=2` to `hero.svg?v=3`).
